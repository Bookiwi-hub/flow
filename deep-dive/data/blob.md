# Blob 데이터

작성자: 채종민

**Blob 데이터**는 **Binary Large Object**의 약자로, 파일이나 이미지, 오디오, 비디오 등 대용량의 **바이너리 데이터**를 의미하는 개념이다. 웹 개발에서 주로 파일 업로드, 다운로드, 이미지 처리 등에 사용되는 중요한 개념이다.

## Blob 데이터란?

Blob은 텍스트가 아닌 **이진 형식(0과 1로 이루어진 데이터)**으로 저장되며, 크기가 큰 데이터를 효율적으로 다룰 수 있도록 설계된 것이다. 예를 들어, 사진 파일이나 PDF 문서 같은 것을 Blob으로 처리할 수 있다.

### 주요 특징

Blob 데이터는 다음과 같은 특징을 가지고 있다.

1. **바이너리 데이터**

   - 텍스트가 아닌 이진 형태로 저장된다. 그래서 이미지, 오디오, 실행 파일 등 다양한 종류의 데이터를 포함할 수 있다.

2. **대용량 처리 가능**

   - 큰 파일도 메모리에 모두 올리지 않고 부분적으로 읽거나 처리할 수 있어 메모리 효율적이다.

3. **불변성**

   - Blob은 한 번 만들어지면 수정할 수 없다. 데이터를 바꾸고 싶다면 새로 Blob을 만들어야 한다.

4. **타입 지정**
   - MIME 타입(예: `image/jpeg`, `application/pdf`)을 설정해서 데이터의 형식을 명확히 알려줄 수 있다.

## 어디에 쓰이나?

웹에서 Blob은 다음과 같은 상황에서 활용된다.

- **파일 업로드**: 사용자가 파일을 선택하면 Blob으로 변환돼 서버에 전송된다.
- **파일 다운로드**: 서버에서 받은 데이터를 Blob으로 만들어 브라우저에서 파일로 저장할 수 있다.
- **이미지 처리**: 캔버스에 그린 그림을 Blob으로 변환해서 저장하거나 업로드할 수 있다.

## 예시

예를 들어, `FileReader`라는 도구로 파일을 Blob 형태로 읽어서 화면에 띄우거나, `fetch`로 서버에서 데이터를 받아 Blob으로 만들어 다운로드 버튼을 누르면 파일이 저장되게 할 수 있다.

## 왜 중요한가?

Blob은 대용량 데이터를 효율적으로 다루고, 다양한 파일 형식을 유연하게 처리할 수 있게 해준다. 웹 애플리케이션에서 파일 관련 작업을 할 때 꼭 필요한 도구이다.
